# 海上搜救联合指挥

源提示词摘要：按海域划设搜索区，协调船艇、直升机、无人机和岸上观察点，记录任务变更、通信与天气影响；离线单位恢复后合并状态，过期位置必须明确提示，并提供低带宽模式。

## 技术栈

Next.js 15、TypeScript、App Router、Mantine、Zustand、TanStack Query、React Hook Form、Zod、next-intl、date-fns、MapLibre。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：`62027`

## 可用流程

- 搜索区从规划、执行到关闭，支持任务范围变更。
- 船艇、直升机、无人机可调派、转入失联、恢复在线。
- 任务单支持新建议题、分配单位、关闭任务和事件留痕。
- 离线模拟与低带宽模式可切换；本地数据由 Zustand persist 保存。

## 低带宽发送账

开启低带宽后，搜救令、指令回执与单位例行位置统一记入通信窗口发送账（容量 5 包位）：

- 容量满先排队；队列中搜救令优先于例行位置，同级先提交先排（最后包位先到先得）。
- 位置包 2 分钟未送出自动作废并释放包位；送达即留档。
- 任务状态变化（推进/关闭/重开）后，该任务未完成的待发指令立即作废释放包位，已送回执的留档保留。
- 搜救令送达后仍占包位，待回执送达才确认归档；回执包本身同样占窗口，满则排队。
- 发送失败仅退回待发队列，下一窗口只重试没送到的；同一指令重复提交只入队一次；已确认指令不重复占包位。

纯逻辑引擎见 `src/lib/comm/`，规则验证脚本（8 条）可编译后用 Node 运行。
